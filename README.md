# Error Search

## Общее описание

Error Search — расширение для VS Code, которое ищет в интернете решение ошибки, на которой стоит курсор, и собирает статистику по найденным ошибкам.

Расширение берёт текст ошибки, которую показывает VS Code, очищает его от лишней информации (пути к файлам, номера строк, имена переменных), добавляет язык программирования и открывает поиск в браузере. Каждый поиск сохраняется, а статистика выводится в строке состояния и на отдельной вкладке с графиками.

Расширение написано на JavaScript и состоит из файлов:

- `extension.js` — весь код расширения
- `package.json` — описание расширения: команды, меню, горячие клавиши
- `.vscode/launch.json` — настройка запуска по F5

## Возможности

- Поиск ошибки на строке с курсором
- Пункт **Find info about error** в меню лампочки (Quick Fix) у каждой ошибки
- Поиск выделенного текста ошибки или фрагмента кода
- Очистка текста ошибки перед поиском
- Сбор статистики поисков
- Счётчик поисков за сегодня в строке состояния
- Дашборд с графиками статистики

## Команды

| Команда | Как вызвать | Результат |
|---|---|---|
| Find info about error | правый клик по строке с ошибкой, `Ctrl+Alt+F`, лампочка | поиск ошибки на строке с курсором |
| Find info about selected error | выделить текст → правый клик, `Cmd+Alt+E` / `Ctrl+Alt+E` | поиск выделенного текста |
| Show error statistics | клик по **Errors today** в строке состояния | открывает дашборд |
| Clear error statistics | кнопка в дашборде или `Cmd+Shift+P` | очищает статистику |

## Очистка текста ошибки

Из текста ошибки удаляется всё, что относится к конкретному коду пользователя и мешает поиску:

| Что удаляется | Пример |
|---|---|
| пути к файлам | `C:\Users\dima\lab3\main.cpp` |
| номера строк и столбцов | `:15:10` |
| имена переменных и функций в кавычках | `'otv'`, `"otv"` |
| слова `error:` и `warning:` | `error:` |
| подсказки компилятора | `did you mean 'std::cout'?` |

```
main.cpp:15:10: error: 'otv' was not declared in this scope
→ Cpp was not declared in this scope

identifier "otv" is undefined
→ Cpp identifier is undefined
```

## Статистика

При каждом поиске сохраняется запись:

| Поле | Описание | Пример |
|---|---|---|
| error | очищенный текст ошибки | `expected ';' at end of declaration` |
| lang | язык программирования | `Cpp` |
| file | имя файла | `test.cpp` |
| day | дата | `2026-10-26` |
| hour | час | `21` |

Дашборд показывает:

- общее число поисков, за сегодня и за последние 7 дней
- топ-10 самых частых ошибок
- число поисков по дням за последнюю неделю
- распределение по времени суток
- распределение по языкам и файлам

## Описание функций

### Обработка ошибок

| Функция | Параметры | Результат |
|---|---|---|
| cleanMessage(text) | text — текст ошибки | очищенный текст для поиска |
| looksLikeError(text) | text — выделенный текст | `true`, если это ошибка, `false`, если код |
| languageName(id) | id — язык файла в VS Code | название языка для поиска |
| searchError(message, languageId, fileName, clean) | текст, язык, файл, нужна ли очистка | сохраняет поиск и открывает браузер |

### Статистика

| Функция | Параметры | Результат |
|---|---|---|
| todayKey(daysAgo) | daysAgo — сколько дней назад | дата в формате `ГГГГ-ММ-ДД` |
| getHistory() | — | массив всех поисков |
| addToHistory(entry) | entry — запись о поиске | сохраняет запись |
| countToday() | — | число поисков за сегодня |
| updateStatus() | — | обновляет счётчик в строке состояния |
| countBy(history, key) | история, поле | пары [значение, количество], по убыванию |
| countLastDays(history, days) | история, число дней | число поисков по дням |
| countByDayPart(history) | история | число поисков по времени суток |

## Установка

1. Упаковать расширение: `npx @vscode/vsce package`
2. В VS Code: **Extensions** → `...` → **Install from VSIX...** → выбрать `error-search-0.0.1.vsix`

## Запуск для разработки

1. Открыть папку проекта в VS Code
2. Нажать `F5` — откроется окно Extension Development Host с загруженным расширением
